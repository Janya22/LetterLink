# Letter Link

Letter Link is a browser-based word-connection puzzle inspired by the general concept of word-linking games such as **The New York Times' Letter Boxed**.

## About the Game

Letter Link challenges players to create words by connecting available letters strategically.

The project explores:

- Game logic and state management
- Word validation and puzzle generation
- Interactive UI design
- Responsive web development
- Progressive Web App (PWA) functionality
- Local game state and persistence

## Tech Stack

- **HTML5** — page structure and game interface
- **CSS3** — styling, responsive layout and animations
- **JavaScript** — game logic and interactivity
- **Web App Manifest** — PWA installation and metadata
- **Service Worker** — caching and offline functionality

## Progressive Web App

Letter Link is designed as a Progressive Web App (PWA), allowing it to be accessed through a browser and installed on supported devices.

The implementation will use:

- Web App Manifest
- Service Worker
- Browser caching
- Responsive design
